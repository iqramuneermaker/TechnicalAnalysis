# TechnicalAnalysis

BDA400 coursework repository (Data Science Tools and Techniques), maintained by Iqra.

## Structure

- `Assignment2/` Preliminary stage: TSX watchlist loader, summary statistics and candlestick charts.
- `Assignment5/` Development phase: indicator functions written from the course pseudocode templates, base R only.
- `Assignment6/` Visualization phase: interactive Shiny dashboard with toggleable overlays, RSI and MACD tabs and crossover trading signals.

To run the dashboard: install shiny, ggplot2 and quantmod, then `shiny::runApp("Assignment6/iqra_portfolio_dashboard.R")`.
